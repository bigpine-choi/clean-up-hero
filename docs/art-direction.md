# 아트 기준

기존에 제작하고 승인받은 세 시안의 표현을 유지하기 위한 기준입니다. 새 디자인을 추가하지 않고, 직원·배경·작업 표현·UI에서 이미 드러난 방향을 정리합니다.

## 대표 플레이 화면

![여러 직원의 이동 공간과 청소 작업이 보이는 세로형 플레이 시안](../assets/concepts/숲속%20야영지%20청소%20경영.png)

첫 화면보다 캐릭터를 작게 배치해 여러 직원의 작업과 동선을 보여줍니다. 청소 현장이 중심이며 상단 정보와 하단 조작부가 이를 보조합니다.

## 전체 분위기

- 밝고 선명한 판타지 색감
- 초록·청록 계열의 숲과 물, 따뜻한 목재·양피지 UI
- 큰 머리와 짧은 팔다리를 가진 귀여운 SD 직원
- 부드러운 명암, 또렷한 윤곽과 역할이 드러나는 도구
- 바닥과 직원의 얼굴을 함께 볼 수 있는 비스듬히 내려다보는 시점
- 풍부한 배경 속에서도 직원과 청소 대상이 바로 구분되는 화면

정확한 색상 코드, 선 두께, 타일 규격, 애니메이션 프레임 수는 아직 정하지 않았습니다. 시안의 비율과 분위기를 참고하되, 파일 해상도를 실제 게임의 고정 해상도 규격으로 보지 않습니다.

## 직원 콘셉트

![고블린 청소부와 세척 마법사와 슬라임 운반꾼의 외형 및 작업 동작](../assets/concepts/세%20명의%20청소%20길드%20직원.png)

| 직원 | 외형과 도구 | 작업 표현 |
| --- | --- | --- |
| 고블린 청소부 | 초록 피부, 노란 두건, 앞치마, 큰 빗자루 | 쓰레기와 잔해를 쓸어 모으기 |
| 세척 마법사 | 보라색 머리, 청록색 모자와 의상, 물뿌리개 | 물과 거품으로 보라색 오염을 세척·정화 |
| 슬라임 운반꾼 | 청록색 둥근 몸, 모자와 가방, 상자·수레 | 회수품을 담아 옮기고 분류하기 |

작은 화면에서도 종족, 도구와 행동으로 역할을 알아볼 수 있는 것이 중요합니다. 세 직원의 표현은 아트 기준이며, 실제 구현 순서나 능력치를 확정한 명세는 아닙니다.

## 작업 현장과 청소 변화

첫 시안의 현장은 용사 일행이 떠난 숲속 야영지입니다. 나무와 풀, 강물, 바위, 텐트, 모닥불 자리가 있고 물약병과 장비 잔해가 흩어져 있습니다.

청소 대상은 주변 배경과 다른 색과 윤곽으로 읽혀야 합니다. 청소가 진행되면 잔해와 오염이 사라지고 돌길·흙바닥·풀밭이 드러나는 변화를 중심에 둡니다.

시안의 작업 시설은 나무 상자, 세척대, 분류함처럼 판타지 세계에 어울리는 형태입니다. 이후 시설을 추가할 때도 이 그림체를 유지한다는 방향이 정리되었습니다. 시설별 상세 규격과 추가 시설 목록은 미정입니다.

## 세로형 UI 구성

| 영역 | 시안에서 보이는 구성 | 유지할 방향 |
| --- | --- | --- |
| 상단 | 제목, 골드·보석 표시, 현장명, 청소율, 작업 인원 | 현재 진행 상태를 빠르게 파악 |
| 중앙 | 직원, 청소 대상, 세척·분류 시설 | 작업 현장과 청소 전후 변화가 충분히 보이도록 구성 |
| 하단 | 직원 아이콘, 고용, 청소 속도·운반 용량, 직원·장비·시설 탭 | 터치 중심의 경영 조작 |

목재 테두리, 양피지 패널, 둥근 버튼과 또렷한 아이콘이 공통 표현입니다. 재화·레벨·인원·진행도·비용·보상은 모두 시안용 예시이며, 보석 아이콘만으로 유료 재화 도입을 결정하지 않습니다.
