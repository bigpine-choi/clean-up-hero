# 게임 콘셉트

현재까지 정한 게임의 방향과 기존 대화에서 제안한 운영 구조를 정리합니다. 화면 방향과 승인된 아트는 기준으로 유지하고, 상세 게임 규칙은 제안으로 구분합니다.

## 확정한 기본 방향

| 항목 | 내용 |
| --- | --- |
| 영문명 | Clean Up, Hero! |
| 한글명 | 용사님, 치우고 가세요! |
| 장르 | 모바일 방치형 경영시뮬레이션 |
| 그래픽 | 2D |
| 화면 방향 | 세로형 |
| 아트 기준 | 밝은 판타지 배경과 귀여운 SD 직원, 목재·양피지 UI |

첫 화면과 직원 콘셉트에 대한 검토 이후, 여러 직원이 함께 일하는 세로형 플레이 화면도 긍정적으로 평가되었습니다. 이후 직원·시설·맵의 표현은 이 시안의 그림체를 기준으로 맞춥니다.

## 세계관과 플레이어 역할

기존에 제안한 설정은 **용사들이 던전을 공략하고 떠난 뒤 남은 현장을 청소하는 업체**입니다. 부서진 무기, 슬라임 점액, 마법 잔해를 처리하며 사업을 키웁니다.

플레이어는 청소업체를 운영하며 의뢰를 선택하고 직원을 배치하고 장비에 투자합니다. 작은 청소팀에서 전문 업체, 나아가 왕국 전역의 청소 길드로 성장하는 방향이 제안되었습니다. 구체적인 의뢰 체계와 성장 단계는 아직 확정하지 않았습니다.

## 핵심 재미의 방향

### 깨끗해지는 과정을 보는 만족감

빗자루가 움직이고 쓰레기 더미가 줄어들며 가려졌던 바닥과 길이 드러나는 변화를 보여줍니다. 청소 결과뿐 아니라 청소 과정 자체를 눈으로 즐길 수 있어야 합니다.

### 직원들의 일을 구경하는 재미

직원이 이동하고, 쓸고, 세척하고, 수거품을 운반하는 모습이 이어집니다. 작은 화면에서도 도구와 실루엣으로 직원의 역할이 구분되는 방향입니다.

### 청소업체를 키우는 경영

일을 마친 보상으로 인력과 장비를 강화하고 더 큰 현장으로 나아가는 흐름을 제안했습니다. 직원 배치, 시설 운영과 확장 방식의 세부 규칙은 검토가 필요합니다.

## 기본 진행 구조 제안

1. 청소 의뢰를 받습니다.
2. 직원들이 자동으로 이동하며 수거·세척·운반합니다.
3. 청소 보수와 회수품을 정산합니다.
4. 인력과 장비를 강화합니다.
5. 더 큰 현장의 의뢰에 도전합니다.

수입원으로는 **청소 용역비와 회수한 폐품·유물의 판매대금**이 제안되었습니다. 판매 방식, 보상 계산과 재화 종류는 확정하지 않았습니다.

이전에 논의한 선택지는 다음과 같습니다.

- 빨리 청소를 끝내고 다음 의뢰를 받기
- 시간을 더 들여 값진 회수품까지 챙기기
- 슬라임이 많은 현장에 세척 장비를 배치하기
- 무기 잔해가 많은 현장에 운반 인력을 더 배치하기

이 항목들은 확정된 시스템이나 이번 저장소 반영의 구현 범위가 아닙니다.

## 시안에 담긴 첫 작업 현장

**용사 일행이 떠난 숲속 야영지**를 첫 아트 장면으로 구체화했습니다. 텐트, 모닥불 자리, 물약병, 방패와 나무 상자, 보라색 오염 자국 등이 보이고, 직원들의 작업 주변으로 돌길과 풀밭이 드러납니다.

직원 콘셉트는 다음 세 종류입니다.

| 직원 | 시안의 작업 표현 |
| --- | --- |
| 고블린 청소부 | 빗자루로 쓸기·수거 |
| 세척 마법사 | 물과 마법을 이용한 세척·정화 |
| 슬라임 운반꾼 | 상자와 수레를 이용한 운반·분류 |

직원별 생산량, 고용 비용, 능력 차이와 해금 순서는 미정입니다.

## 화면에서 확인할 정보

승인된 플레이 화면의 구성은 상단 정보, 중앙 청소 현장, 하단 조작부입니다.

- 상단: 재화, 현장명, 청소 진행도와 작업 인원
- 중앙: 여러 직원의 작업과 이동, 청소 전후의 변화, 세척·수거·분류 시설
- 하단: 직원 고용, 청소 속도·운반 용량 업그레이드, 직원·장비·시설 관리

시안의 여섯 직원과 3,150 골드, 보석 아이콘, 청소율 42%, 고용 및 업그레이드 비용 등은 화면 구성을 위한 예시입니다. 이를 인원 제한, 확정 밸런스, 유료 재화나 과금 모델로 해석하지 않습니다.

## 아직 결정하지 않은 사항

- 실제 의뢰와 보상 계산, 폐품·유물 판매 규칙
- 직원·시설별 수치, 배치 방식, 해금과 확장 순서
- 첫 시제품의 정확한 콘텐츠 수량
- 개발 엔진과 언어, 운영체제별 출시 순서

개발 도구와 시제품 범위에 대한 기존 제안은 [개발 계획](development-plan.md)에 정리합니다.
