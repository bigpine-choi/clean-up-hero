# 게임 콘셉트

**직원은 자동으로 일하고, 사장은 계속 판단하는 청소회사 경영 게임**을 만듭니다. 청소 전후를 보는 만족감, 운영 판단의 효과, 다음 현장에 대한 호기심을 연결합니다. 방치 기능은 플레이어가 정한 운영 방침을 실행하는 수단입니다.

첫 화면과 직원 콘셉트, 여러 직원이 함께 일하는 세로형 플레이 화면은 승인된 아트 기준으로 유지합니다. 이번 경영 규칙 시제품의 임시 화면과 수치가 최종 아트나 밸런스를 확정하지는 않습니다.

## 세계관과 플레이어 역할

플레이어는 **용사들이 던전을 공략하고 떠난 뒤 남은 현장을 청소하는 업체의 사장**입니다. 부서진 무기, 슬라임 점액, 마법 잔해를 처리하고 회사의 인력과 자금을 운영합니다.

작은 청소팀에서 전문 업체, 왕국 전역의 청소 길드로 성장하는 장기 방향을 유지합니다. 성장은 창고·장비·직원·복원한 공간의 변화로 보여주는 것을 목표로 합니다. 구체적인 회사 확장 단계는 기본 경영의 재미를 검증한 뒤 정합니다.

## 플레이어의 세 가지 판단

| 판단 | 고려할 내용 | 결과를 보여줄 방식 |
| --- | --- | --- |
| 어떤 의뢰를 받을까? | 보수와 물량, 필요한 인력·장비, 현재 자금 | 작업 시간과 실제 이익, 다음 의뢰를 받을 여력 |
| 사람과 장비를 어디에 쓸까? | 세척과 운반 중 막히는 작업, 장비 비용과 시간 절약 | 현장의 적치물·직원 동작, 처리 속도와 비용 변화 |
| 무엇을 남기는 거래를 할까? | 청소 보수를 더 받을지, 회수품 권리를 가져올지, 다음 거래를 고려할지 | 이번 손익과 회수품·단골 관계·후속 의뢰의 변화 |

세 번째 판단은 장기 설계 방향입니다. **첫 버전은 의뢰 선택과 팀 배치부터 구현하며, 보수·유물 소유권 협상, 단골과 평판은 이후 확장합니다.**

## 첫 버전의 진행 구조

1. 보수·물량·비용이 공개된 의뢰를 비교합니다.
2. 총 4명의 직원을 세척과 운반에 나누어 배치합니다. 두 역할에 최소 1명씩 필요합니다.
3. 필요하면 해당 현장만 사용할 수레 또는 세척기를 임대합니다.
4. 직원들이 자동으로 작업합니다. 적치물이 쌓이거나 세척 속도가 부족하면 작업 중에도 팀 구성을 바꿉니다.
5. 예상·실제 작업 시간과 이익, 결과가 달라진 원인을 확인합니다.
6. 다음 의뢰를 직접 선택합니다.

자동 작업은 1배·4배 속도로 볼 수 있습니다. 진행 배속은 기다리는 시간을 바꾸며, 인력·장비와 물량이 같으면 게임 내 작업 시간과 손익은 같아야 합니다.

직원 고용과 영구 장비 투자를 반복하기 전에, **같은 인원으로도 현장에 따라 다른 배치가 유리한가**를 검증합니다. 수레·세척기 임대료는 한 현장의 비용이며 영구 구매와 구분합니다.

### 현장별 다른 문제

| 시제품 현장 | 비교할 운영 문제 |
| --- | --- |
| 안정적인 야영지 | 적은 물량과 안정적인 수입, 기본 작업 흐름 이해 |
| 세척 물량이 많은 욕탕 | 운반에 과도하게 배치하면 세척이 늦어짐 |
| 운반 물량이 많은 유물고 | 수거품이 쌓이면 운반 인력·수레의 가치가 커짐 |
| 복구 의뢰 | 손실 후에도 다시 운영을 이어갈 수 있는 선택지 |

유물고의 이름은 협상 기능을 뜻하지 않습니다. 첫 버전의 계약·정산 조건은 사전에 공개하며, 유물 소유권을 따로 협상하거나 무작위 유물 보상을 받는 시스템은 포함하지 않습니다.

## 작업과 손익이 연결되는 규칙

세척한 물량은 현장 적치물로 이동하고, 운반이 끝나야 처리가 완료됩니다. 적치 공간이 차면 세척 작업이 막힙니다. 운반 인력을 늘려 적치물이 줄어드는 모습을 보여주어 재배치의 효과를 읽을 수 있게 합니다.

손익은 공개된 수입과 실제 작업에 든 비용으로 계산합니다.

**현장 이익 = 계약상 수입 − 실제 작업 시간에 따른 인건비 − 해당 현장 장비 임대료**

초기 배치 기준 예상 시간·이익과 실제 결과를 함께 보여줍니다. 첫 규칙은 같은 물량과 운영에서 같은 결과가 나오는 방식입니다. 초기 배치를 유지하면 예상과 실제가 일치하고, 작업 중 재배치하면 시간과 손익이 달라질 수 있습니다.

운영 손실은 느린 처리, 인력 구성과 장비 비용 같은 설명 가능한 원인에서 발생해야 합니다. 초기 시제품의 비용은 작업에 소요된 게임 내 시간만 반영하고, 완료한 현장을 화면에 띄워둔 시간에는 인건비를 더하지 않습니다.

위험한 의뢰라는 표현을 곧바로 무작위 사고나 직원 사망으로 구현하지 않습니다. 첫 버전에서 검증할 위험은 공개된 물량과 비용을 잘못 판단해 발생하는 손실입니다. 손실 이후에는 복구 의뢰로 운영을 이어갈 수 있게 하여, 이전 판단을 개선할 기회를 남깁니다.

## 핵심 재미와 표현

### 청소 전후의 쾌감

쓰레기 더미가 줄고 얼룩 아래의 바닥과 길이 드러나는 변화를 보여줍니다. 완료 보상창이 없어도 청소 과정을 보고 싶어지는 것이 목표입니다. 소리와 동작의 만족감은 최종 아트·연출을 구현할 때 별도로 검증합니다.

### 내 판단이 만드는 운영 개선

운반 직원을 늘리자 쌓이던 적치물이 줄고 세척 작업이 다시 진행되는 식으로 원인과 결과를 연결합니다. 숫자의 복잡함보다 현장의 문제를 보고 고쳐보는 경험을 우선합니다.

### 다음 현장에 대한 호기심

다음 현장은 배경만 바뀌는 상위 가격 의뢰가 아니라 다른 작업 문제와 발견을 예고해야 합니다. 직원 조합을 바꿔보거나 새로운 현장을 확인하고 싶어지는지를 검증합니다. 잠긴 방, 수상한 흔적과 주민의 귀환은 기본 흐름이 재미있어진 뒤 추가할 콘텐츠 후보입니다.

## 방치 기능의 역할

회사는 플레이어가 선택한 의뢰와 운영 방침을 따라 일합니다. 복귀했을 때 직원들이 해놓은 일과 남은 문제를 보고 다음 판단을 할 수 있게 하는 것이 목표입니다.

첫 시제품은 다음 의뢰를 자동 수주하지 않습니다. 저장·오프라인 진행, 반복 의뢰 운영은 후속 단계에서 계산 범위와 정책을 정합니다. 방치 확장 이후에도 자금과 인력을 무시한 무제한 자동 수주로 경영 판단을 생략하지 않습니다.

## 승인된 아트와 직원 콘셉트

**용사 일행이 떠난 숲속 야영지**를 첫 아트 장면으로 구체화했습니다. 텐트, 모닥불 자리, 물약병, 방패와 나무 상자, 보라색 오염 자국 주변으로 돌길과 풀밭이 드러납니다.

| 직원 | 시안의 작업 표현 |
| --- | --- |
| 고블린 청소부 | 빗자루로 쓸기·수거 |
| 세척 마법사 | 물과 마법을 이용한 세척·정화 |
| 슬라임 운반꾼 | 상자와 수레를 이용한 운반·분류 |

위 세 종류는 외형과 동작의 아트 기준입니다. 경영 규칙 시제품의 세척·운반 두 역할과 동일한 콘텐츠 수량을 뜻하지 않습니다. 직원별 능력, 고용 비용과 해금 순서는 후속 설계 사항입니다.

## 화면에서 확인할 정보

상단 정보, 중앙 청소 현장, 하단 경영 조작부라는 승인된 세로형 구성을 유지합니다.

- 상단: 현장명, 회사 자금, 처리 진행도와 작업 인원
- 중앙: 세척·운반 작업, 적치량과 막힌 작업, 청소 전후 변화
- 하단: 의뢰 비교, 팀 배치와 장비 선택, 작업 중 재배치
- 정산: 예상·실제 시간과 이익, 비용 내역과 결과의 원인

시안의 여섯 직원, 3,150 골드, 보석 아이콘, 청소율 42%, 고용·업그레이드 비용은 화면 구성용 예시입니다. 인원 제한, 확정 밸런스, 유료 재화나 과금 모델로 해석하지 않습니다.

- 단골·평판과 새로운 현장·발견의 연결
- 저장·오프라인 진행의 범위와 운영 정책
- 제작 엔진·언어, Android 등 출시 순서와 최종 수치
