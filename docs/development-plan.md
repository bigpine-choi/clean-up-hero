# 개발 계획

세로형 2D 모바일 방치형 경영시뮬레이션이라는 확정 방향을 바탕으로, 기존에 논의한 시제품 범위와 다음 구현 흐름을 정리합니다. **아래 구현 단계와 수량, 개발 도구는 제안이며 구현 완료나 최종 확정을 뜻하지 않습니다.**

## 현재 상태

- 게임명, 장르, 2D 그래픽, 세로형 화면 방향 결정
- 첫 화면과 직원 콘셉트, 실제 플레이 화면 시안 제작 및 검토
- 원본 PNG 3종과 게임 콘셉트·아트 기준·개발 계획 보관
- 실행 가능한 게임과 게임 코드는 아직 없음

## 첫 시제품의 목표

기존에 제안한 목표는 **휴대폰에서 약 10분 동안 청소와 성장을 반복해 보며 재미를 확인할 수 있는 작은 플레이 버전**입니다.

직원이 이동하며 청소하고 쓰레기가 사라지는 모습, 완료 보상을 받아 고용·업그레이드로 이어지는 흐름을 먼저 확인합니다. 콘텐츠를 늘리기 전에 청소 과정과 성장의 연결이 재미있는지를 봅니다.

10분은 초기 체험 목표로 제안된 값이며, 세션 길이 제한이나 출시 기준으로 확정한 수치는 아닙니다.

## 초기 범위 제안

| 항목 | 기존에 제안한 범위 |
| --- | --- |
| 작업 현장 | 던전 1개 |
| 직원 | 청소 직원 1종 |
| 청소 대상 | 잔해 3종 |
| 자동 작업 | 이동·청소·운반 |
| 보상 | 청소 완료 보상 |
| 성장 | 청소 속도·운반량 업그레이드 |
| 지속성 | 저장·불러오기, 종료 중 작업 진행 계산 |

이 수량은 첫 논의의 최소 시제품 제안입니다. 승인된 아트의 직원 3종이나 플레이 시안의 직원 6명이 첫 구현 수량을 확정한 것은 아닙니다. 첫 현장으로 시안의 숲속 야영지를 사용할지, 구현할 직원과 잔해를 무엇으로 할지는 개발 착수 때 정해야 합니다.

## 단계별 구현 순서 제안

아래 순서는 기존에 논의한 기능을 작은 플레이 버전으로 이어가기 위해 정리한 제안입니다. 일정과 각 단계의 완료 날짜는 정하지 않았습니다.

### 1단계 세로형 작업 현장

승인된 시안을 기준으로 상단 상태 정보, 중앙 작업 현장, 하단 경영 조작부를 구성합니다. 작은 직원 여러 명이 움직일 수 있는 공간과 청소 대상이 읽히는지를 확인합니다.

확인할 결과: 직원·쓰레기·바닥과 조작부가 구분되고, 작업 현장이 충분히 크게 보이는 화면.

### 2단계 자동 청소와 운반

직원이 청소 대상으로 이동하고 작업하고 회수품을 운반하는 기본 흐름을 만듭니다. 쓰레기가 줄고 바닥이 드러나는 변화가 보이도록 합니다.

확인할 결과: 직원의 작업 과정과 청소 전후 변화가 화면에서 분명히 보이는 작은 현장.

### 3단계 보상과 성장

청소 완료 보상을 연결하고, 보상으로 인력을 고용하거나 청소 속도·운반 용량을 강화하는 흐름을 확인합니다. 실제 보상과 비용은 별도로 정하며 시안의 예시 수치를 그대로 확정하지 않습니다.

확인할 결과: 청소 결과가 다음 작업의 성장으로 이어지는 반복 가능한 플레이 흐름.

### 4단계 저장과 방치 진행

기존 제안에 포함된 저장·불러오기와 종료 중 작업 진행 계산을 연결합니다. 오프라인 진행의 상한, 계산식과 보상 방식은 아직 정하지 않았습니다.

확인할 결과: 다시 접속했을 때 작업과 성장 상태를 이어 볼 수 있는 시제품.

### 5단계 짧은 플레이 검토 후 확장 판단

휴대폰에서 청소·보상·성장을 반복해 보고, 청소를 구경하는 재미와 조작의 이해도를 확인합니다. 그 결과를 보고 직원 종류와 던전을 늘린다는 기존 방향을 따릅니다.

확인할 결과: 첫 시제품에서 유지할 부분과 개선할 부분, 콘텐츠 확장이 필요한지에 대한 판단.

## 개발 도구 제안

이전에 **Godot + GDScript, Android 우선**을 추천했지만, 사용자가 선택을 확정한 기록은 없습니다. 현재의 기술 스택이나 출시 순서로 간주하지 않습니다.

엔진, 언어와 운영체제별 작업 순서는 실제 구현 착수 전에 확정해야 합니다. 이 문서에서는 새 개발 도구나 추가 기능을 제안하지 않습니다.

## 착수 전에 확인할 사항

- 사용할 엔진과 언어, 첫 실행 대상 기기
- 첫 작업 현장, 직원과 잔해의 구체적인 구성
- 고용·보상·업그레이드의 초기 수치
- 오프라인 진행의 계산 범위와 저장할 상태

이번 문서·이미지 반영에는 게임 구현, 빌드 환경 설정, 배포나 테스트 자동화가 포함되지 않습니다.
