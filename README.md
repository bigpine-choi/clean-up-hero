# Clean Up, Hero!
## 용사님, 치우고 가세요!

**직원은 자동으로 일하고, 사장은 계속 판단하는 청소회사 경영 게임.**

용사들이 떠난 현장을 정리하는 작은 청소업체를 운영하는 세로형 2D 모바일 게임입니다. 중심은 **의뢰 선택, 인력·장비 배치, 선택의 결과를 이해하는 경영**에 둡니다. 방치 기능은 플레이어가 정한 운영 방침대로 직원들이 일하도록 돕습니다.

현재는 승인된 콘셉트와 아트를 유지하며 **경영 규칙을 검증하는 브라우저 시제품**을 만드는 단계입니다. 브라우저 시제품은 Android 게임이나 최종 아트가 적용된 완성본이 아닙니다. 제작 엔진과 출시 순서는 아직 확정하지 않았습니다.

## 첫 버전의 플레이

**의뢰 선택 → 팀 배치 → 자동 작업·재배치 → 손익 확인**

- 공개된 보수, 물량과 비용을 보고 자금·인력에 맞는 의뢰를 선택합니다.
- 총 4명을 세척과 운반에 배치하고, 필요하면 해당 현장에 사용할 장비를 임대합니다.
- 자동 작업 중 적치물이 쌓이는지, 세척과 운반 중 어느 작업이 막히는지 보고 인력을 다시 배치합니다.
- 예상·실제 작업 시간과 이익, 차이가 생긴 이유를 확인하고 다음 의뢰를 결정합니다.

작업 화면에서 1배·4배 진행 속도를 선택할 수 있습니다. 진행 배속은 화면에서 기다리는 시간을 줄이며, 같은 운영의 작업 시간과 비용 계산은 동일합니다.

안정적인 야영지, 세척 물량이 많은 욕탕, 운반 물량이 많은 유물고와 복구 의뢰를 비교합니다. 이번 시제품의 위험은 공개된 물량과 비용에서 발생하는 운영 손실입니다. 무작위 사고, 유물 소유권 협상, 단골과 평판은 후속 범위입니다.

## 브라우저 시제품 실행

`prototype/play.html`을 브라우저에서 열면 별도 설치 없이 플레이할 수 있습니다. 이 파일은 소스에서 생성한 단일 파일 시제품입니다.

소스를 변경한 뒤 단일 파일을 다시 만들려면 실행합니다.

```bash
node prototype/build.mjs
```

저장소 루트에서 아래 명령을 실행한 뒤 [http://localhost:8765/](http://localhost:8765/)를 엽니다.

```bash
python3 -m http.server 8765 --directory prototype
```

규칙 검증은 Node.js에서 실행합니다.

```bash
node --test prototype/engine.test.mjs
```

영구 장비 구매, 직원 고용·성장과 저장·오프라인 진행은 기본 경영 흐름을 검토한 뒤 확장합니다. 다음 의뢰는 플레이어가 직접 선택하며, 작업 비용은 작업에 소요된 게임 내 시간에 대해서만 계산합니다.

## 세로형 플레이 화면 시안

![여섯 직원이 청소와 운반을 하는 숲속 야영지의 세로형 플레이 화면 시안](assets/concepts/숲속%20야영지%20청소%20경영.png)

작은 직원들이 쓸기·세척·운반 작업을 하고, 세척 및 분류 시설을 이용하는 승인된 아트 시안입니다. 밝은 판타지 배경, 귀여운 SD 직원, 목재·양피지 표현을 이후 아트의 기준으로 유지합니다.

**시안의 인원, 재화, 청소율, 레벨, 보상과 비용은 예시입니다.** 하단의 고용·업그레이드 버튼도 이번 경영 시제품의 기능 확정을 뜻하지 않습니다. 실제 밸런스와 유료 재화 구조를 확정한 수치가 아닙니다.
