# Clean Up, Hero!
## 용사님, 치우고 가세요!

방치형 모바일 경영시뮬레이터 게임 개발 프로젝트.

용사들이 떠난 현장을 정리하는 작은 청소업체를 운영하는 2D 모바일 게임을 구상합니다. 직원들이 일하는 모습과 청소 전후의 변화가 잘 보이는 **세로형 화면**을 기준으로 합니다.

현재는 **콘셉트와 아트 방향을 정리한 단계**입니다. 아래 이미지는 기존에 제작하고 검토한 시안이며, 실행 가능한 게임 화면을 캡처한 것은 아닙니다.

## 세로형 플레이 화면 시안

![여섯 직원이 청소와 운반을 하는 숲속 야영지의 세로형 플레이 화면 시안](assets/concepts/숲속%20야영지%20청소%20경영.png)

작은 직원들이 쓸기·세척·운반 작업을 하고, 세척 및 분류 시설을 이용하는 구성을 보여줍니다. 하단에는 직원 고용, 청소 속도·운반 용량 업그레이드, 직원·장비·시설 관리 버튼이 있습니다.

**시안에 보이는 인원, 재화, 청소율, 레벨, 보상과 비용은 예시입니다.** 실제 밸런스나 유료 재화 구조를 확정한 수치가 아닙니다.

## 정해진 방향

- 영문명: **Clean Up, Hero!**
- 한글명: **용사님, 치우고 가세요!**
- 장르: 모바일 방치형 경영시뮬레이션
- 그래픽: 2D
- 화면: 세로형
- 아트·UI: 기존 시안의 밝은 판타지 배경, 귀여운 SD 직원, 목재·양피지 표현을 기준으로 유지

세부 경제 구조, 첫 구현 범위와 개발 도구는 아래 문서에서 **제안**으로 구분합니다.
